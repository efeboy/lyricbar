# LyricBar

A macOS menu bar app that shows time-synced lyrics for whatever **Spotify** or
**Apple Music** is currently playing. SwiftUI `MenuBarExtra`, no third-party
dependencies, no Dock icon.

<img src="LyricBar/Assets.xcassets/AppIcon.appiconset/icon_128x128.png" width="96" alt="LyricBar icon">

## Requirements

- macOS 14.0 or later
- Xcode 16 or later (the project uses synchronized folder groups)

## Build and run

```sh
open LyricBar.xcodeproj
```

Select the **LyricBar** scheme and press ⌘R. The icon appears in the menu bar.

There is no package manifest, no `launchctl`, and no signing dance — it is a
plain Xcode app target, because `MenuBarExtra` and `SMAppService` both require a
real app bundle.

### First run

macOS prompts once per controlled app for **Automation** access to Spotify and
Music. Both must be allowed, or the app runs and silently shows no lyrics. To
check or change it later: System Settings ▸ Privacy & Security ▸ Automation.

**Open at login** is a menu toggle backed by `SMAppService.mainApp`; the system
lists it under System Settings ▸ General ▸ Login Items.

## Tests

```sh
xcodebuild -project LyricBar.xcodeproj -scheme LyricBar test
```

`LyricBarTests` uses Swift Testing and covers the pure logic: LRC parsing, the
active-line binary search, and LRCLIB's duration matching. It is a hosted test
bundle, so the app launches as the test host — `PlaybackModel` detects that and
leaves its poll loop off, so tests never touch Spotify, Music, or the network.

A green build proves nothing about whether the menu bar item renders or whether
Automation was granted. Verify UI-adjacent behavior by running the app.

## Layout

```
LyricBar/                     app sources (synchronized folder — add a file, it builds)
├── LyricBarApp.swift         MenuBarExtra scene: label and menu
├── PlaybackModel.swift       @Observable model; owns the poll loop
├── LoginItem.swift           SMAppService wrapper
├── Playback/                 NowPlaying snapshot + Spotify / Music AppleScript bridges
├── Lyrics/                   LRC parser + LRCLIB client
├── Assets.xcassets           app icon, accent color
└── LyricBar.entitlements     sandbox off, Apple Events on
LyricBarTests/                Swift Testing suites
```

`Info.plist` is generated by Xcode from `INFOPLIST_KEY_*` build settings —
`LSUIElement` and `NSAppleEventsUsageDescription` are set there, not in a file.

Architecture, the API notes, and the constraints that are easy to break are
documented in [CLAUDE.md](CLAUDE.md).

## Lyrics source

Lyrics come from [LRCLIB](https://lrclib.net), a free, no-key community lyrics
database. Tracks with no synced match, and instrumentals, show the icon alone.
